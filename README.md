# 👑 지윤님 비서실 — 웹 대시보드

개인 비서실 느낌의 모바일 친화 웹 대시보드입니다. 오피스 맵 · 회의실 · 발주·리뷰 · 구독·납입 · 메모장 5개 탭으로 이루어져 있습니다.

## 🔒 개인정보 안내 (중요)

- 이 페이지는 **공개 주소**에 올라가는 정적 페이지입니다. HTML/JS 어디에도 실제 이름·전화번호·주소·계좌번호·카드정보·실제 거래처 정보가 들어 있지 않습니다.
- 화면에 처음 보이는 항목은 모두 **가상의 예시 데이터**입니다. (`샘플상사`, `예시 품목 A`, `예시은행`, `관리비 (예시)` …)
- 직접 입력한 내용은 **그 브라우저의 localStorage에만** 저장되고 서버로 전송되지 않습니다. 다른 기기·다른 브라우저와 공유되지 않습니다.
- 공개 페이지이므로 실제 계좌번호·카드번호·주민등록번호는 입력하지 마세요. 납입 항목의 계좌는 `예시은행 · 자동이체`처럼 메모 수준으로만 적는 것을 권합니다.
- 검색엔진 수집을 막기 위해 `noindex` 메타 태그를 넣어 두었습니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 🗺️ 오피스 맵 | 클레이/기본 스타일 토글, 움직임 ON/OFF, 5개 구역 핀(토라·토끼·곰·고양이·강아지) 클릭 시 한마디 + 관련 탭 이동 |
| 💬 회의실 | 아이디어 카드 추가(제목·분류·내용·목표일), 진행/완료 토글, 삭제 |
| 📦 발주·리뷰 | 발주(거래처·품목·수량·납기일·메모) / 리뷰(상품명·마감일·포토 여부) 관리, 대기·완료 카운트 |
| 💳 구독·납입 | 구독 현황(서비스명·결제일·월금액·사용/해지), 납입일 체크(항목·기한·금액·은행 메모), 미납 총액 자동 합산 |
| 📝 메모장 | 빠른 메모 작성, 📌 핀 고정, 수정, 삭제 |

데이터 관리(오피스 맵 하단): **JSON 내보내기 / 불러오기**, **초기화(예시 복원)**, **예시 비우기**.

## 파일

```
index.html                 # 앱 전체 (HTML + CSS + JS, 의존성 없음)
assets/office-basic.webp   # 기본 스타일 오피스 맵 (페이지에서 사용)
assets/office-clay.webp    # 클레이 스타일 오피스 맵 (페이지에서 사용)
assets/office-basic.png    # 원본 고해상도 (1400px)
assets/office-clay.png     # 원본 고해상도 (1244px)
```

## 로컬에서 열기

`index.html`을 브라우저로 열면 바로 동작합니다. (파일을 직접 열어도 localStorage는 동작합니다.)

## GitHub Pages로 공개하기

저장소 **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
잠시 뒤 `https://<계정>.github.io/test-site/` 주소로 열립니다.
